# Local GUI audit

The local GUI of the framework R package was retired in f903a57 ("retire the local GUI; gui() is a deprecated stub pointing to Framework Cloud"). This audit lists every screen, setting, and action of the GUI at f903a57^ (`gui-dev/src`, served by `R/gui.R` and `R/gui_helpers.R`) and where Framework Cloud provides it.

GUI screens: Projects, New project, Settings (Overview, Basics, Project structure, Packages, Quarto, Git & Hooks, AI Assistants, Scaffold Behavior, Templates, Connections, .env Defaults), Project detail (Overview, Basics, Project structure, Rendered notebooks, Data catalog, Connections, Input files, Output files, Saved results, Packages, AI Assistants, Quarto, Git & Hooks, Scaffold Behavior, Environment variables), and Docs.

Cloud locations: the blueprint editor tabs (`Blueprints/Builder.vue`), New project and Edit project (`Projects/Create.vue`), both through `ChoicesEditor.vue`; Project structures (`Pieces/Edit.vue`); Settings (Default blueprint, Personal data); the project Overview (`Projects/Show.vue`); and the API and MCP tools.

## Implementation

- `App\Support\Templates`: kinds, paths by language and format, `files()` for the layer, `split()` back to the editor, and Framework's stubs from `resources/stubs/`. Templates keep `{{ title }}` placeholders; files are written with `template` off so `make_notebook()` fills them.
- `App\Support\Connections`: `variables` rows become `env`, beside the variables connections read. `split()` returns a variable to the editor unless it is a connection's own with its own default. Secret-looking names must stay empty.
- `Catalog::choices()`: a blueprint's packages that no visible set offers reopen as `package_definitions`, not as catalog overrides. Before, such a package failed validation when the blueprint was saved again.
- `BlueprintInput`, `Resolver`, `ProjectsController`, and `WelcomeController` pass `templates` and `package_definitions` like connections: validated, resolved, stored as project choices, and reopened by Edit project. Extra settings YAML no longer shows what the tabs hold.
- MCP blueprint tools document `package_definitions` and `templates`.
- Tests: `tests/Feature/GuiSettingsTest.php`.
